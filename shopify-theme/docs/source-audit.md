# Source audit: siriguela.site → Vereda

Reference examined: the static Siriguela site in this repository (root `index.html`, `produto.html`, `assets/css/tokens.css`, `assets/css/style.css`, `assets/js/app.js`, `movimento.js`, `locomotiva.js`, `produtos.js`, `checkout/` and `avisos/` workers). The original site was **not modified**; the theme lives in `shopify-theme/` only.

## What the reference does well (kept as language, not code)

| Element in Siriguela | Kept as an idea in Vereda |
| --- | --- |
| "Galeria" direction: ~90% neutral (linen, ink, sand), colour reserved for signals | Five colour schemes per preset; the **signal** colour is decorative only (dots, markers), never body text |
| The red "ponto" closing headlines and the logo | `signal` snippet + "Signal mark" setting (dot / square / none), per-heading toggles |
| Huge, tight display type ("Só estampa.") anchored to the right margin | Hero composition "Margin", display scale `--heading-scale`, tracking setting |
| Mono, uppercase index labels (01, 02 · coordinates) | `meta` font picker (monospaced by default), numbered product cards, numbered tiles and mosaic captions |
| "Índice" list of prints with origin | **Editorial index** section: numbered rows, origin detail, image revealed on hover / inline on touch |
| Endless horizontal video reel in the hero | **Media reel** section (CSS animation, pause button, reduced-motion safe, videos play only in view) |
| "Capa" product page: oversized name beside the first photo, mosaic below | **Cover** product layout: first media full width, giant title in a sticky buy column, mosaic of remaining media |
| Hairline 1px rules, zero radius | `show_rules` setting, radius settings default to 0 (Murta preset uses round shapes) |
| Self-hosted fonts, deferred video loading, Lighthouse > 90 | Shopify font library only, `preload: none` videos started by IntersectionObserver, no third-party JS |

## Redesigned to work for any store

- Copy, colours and photography are now **merchant data** (settings, blocks, Shopify objects); nothing about swimwear, Brazil or prints remains.
- The single-catalogue grid became `featured-collection`, `collection-list`, `main-collection` with native filtering.
- The "safra" (monthly pre-order window), coupon copy and fixed pricing were dropped: they are business rules, not theme features.
- The size table became generic collapsible tabs and pages.

## Reimplemented natively in Shopify

| Siriguela implementation | Vereda implementation |
| --- | --- |
| `produtos.js` hard-coded catalogue | `product`, `collection`, `search`, `recommendations` objects |
| localStorage bag + Nextout worker (`/api/checkout`) | Native cart (`/cart/add.js`, `/cart/change.js`) with Section Rendering API, Shopify checkout |
| Email list worker (`avisos/`) | Native `customer` form (newsletter) |
| Static product pages generated by Python | `templates/product.json` + `main-product` section with blocks and `@app` blocks |
| Manual `srcset` WebP variants | `image_url` + `image_tag` with widths and focal points |

## Abandoned

- **Lenis + GSAP ScrollTrigger + "locomotiva"** (smooth scroll, parallax): scroll hijacking hurts accessibility, conflicts with the theme editor and adds weight. Replaced by a 30-line IntersectionObserver reveal that is off for `prefers-reduced-motion` and can be disabled in settings.
- Cloudflare Workers (checkout, notices) and any runtime external call.
- Letter-by-letter title animation (`data-letras`): screen-reader noise, layout shift risk.
- AV1/HEVC triple video encoding: Shopify-hosted video handles formats.

## Risks

- **Originality**: Vereda is written from scratch (no Dawn/Horizon code). The Skeleton theme was consulted only as a reference for conventions; no files were copied. Review should still be done by a human before submission.
- **Distinctiveness**: Shopify rejects reskins. The editorial index, cover PDP, margin hero, media reel and signal system are the differentiators; they must be showcased in the demo store.
- **Fonts**: default handles (`inter_n5`, `inter_n4`, `space_mono_n4`, `lora_n4`) must be verified in a real store; if a handle is not in the font library the editor falls back silently.
- **Untested on Shopify runtime**: rendering was verified with a local Liquid simulator (`tools/preview`); cart, variant (option_values), filters, predictive search and pickup endpoints need a development store.
