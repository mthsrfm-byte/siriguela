# Customization guide

Everything below is done in the theme editor. No code is required.

## Global (Theme settings)
| Group | What it controls |
|---|---|
| Logo and favicon | Logo image and width; favicon |
| Colors | Five color schemes. Each has background (or gradient), surface, text, secondary text, lines, button, button label and **signal** |
| Typography | Heading, body and label fonts (Shopify font library), heading size scale, letter spacing, uppercase headings, body size scale, uppercase labels |
| Layout | Page width, page margin, grid spacing, space between sections (compact / balanced / airy), hairline rules |
| Buttons and shapes | Button, input and image corner radius; signal mark (dot / square / none) |
| Product cards | Image ratio (portrait / square / tall / adapt), fill or fit, second image on hover, vendor, index numbers, swatches, quick add |
| Motion | Reveal on scroll, image hover effects. Both are always off for visitors who prefer reduced motion |
| Cart | Drawer or page, order notes, currency codes |
| Search | Search suggestions |
| Social media | Instagram, TikTok, Pinterest, Facebook, YouTube, X |

### The signal
The signal is Vereda's accent: a small dot placed after selected headings, on sale badges and on error messages. It is intentionally never used as a text color, so any signal color keeps the store accessible. Turn it off per heading or globally ("Signal mark: None").

## Sections
| Section | Use it for | Key options |
|---|---|---|
| Editorial hero | First impression | Separate desktop and mobile image or video, three compositions (Margin, Centered, Split), height, overlay, two buttons |
| Featured collection | Products from a collection | Grid or horizontal scroll, 2–5 columns, 1–2 on mobile |
| Collection list | Category tiles | Custom title and image per tile, ratio |
| Editorial index | Numbered list of products or stories | Each row: product or custom title, detail line, image, link |
| Image with text | Storytelling | Image first or text first, half or wide image, text position, kicker/heading/text/button blocks |
| Statement | Brand voice | Kicker, large text, two-column body, link |
| Lookbook mosaic | Campaign images | Staggered, feature or even pattern; caption and tagged product per image |
| Media reel | Moving strip of images or short videos | Height, loop duration, accessible name, pause button |
| Facts | Materials, shipping, returns | 2–4 columns, optional image |
| Quotes | Reviews or press | Quote and source per block (enter only real quotes) |
| Collapsible content | FAQ | Text or page content per row |
| Video | Shopify video or YouTube/Vimeo | Muted loop or player controls; external videos load only after pressing play |
| Featured product | Spotlight one product | Title, price, text, variant picker, buy buttons, app blocks |
| Email signup | Newsletter | Heading, text, color scheme |
| Custom Liquid, Apps | Integrations | Liquid code, app blocks |

## Product page
Layout **Cover** (first image large, others as a mosaic) or **Stack**. Blocks: title, vendor, text, price, variant picker (buttons or dropdown; swatches when option values have them), quantity, buy buttons (dynamic checkout, gift card recipient form), pickup availability, description, collapsible tabs, share, Custom Liquid and app blocks. Add the **Product recommendations** section twice to show both complementary and related products.

## Presets
- **Vereda**: linen, ink and terracotta; Inter + Space Mono; square shapes; portrait cards with index numbers.
- **Murta**: oat, sage and deep green; Lora + Inter; rounded buttons and images; square cards with fitted product shots.
